# Dopamine

Rootless полумягкий (semi-untethered) джейлбрейк для iOS 15.0 - 17.3.1 (arm64e), iOS 15.0 - 18.7.1, 26.0 - 26.0.1 (A12/A13) и iOS 15.0 - 18.7.1 (arm64). Дополнительная информация будет добавлена здесь в ближайшее время.

Обратите внимание, что все issues, связанные с поддержкой версий, будут удаляться без ответа.
